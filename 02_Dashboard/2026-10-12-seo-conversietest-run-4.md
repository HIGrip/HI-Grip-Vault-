### Gebouwd (concept — alleen in het testthema, niets live)

Thema `SEO TEST - HI Grip WEBSITE` (ID 200249901383, niet-gepubliceerd, bevestigd via `themes(first:20)`; het live thema `Live HÏ Grip WEBSITE` is niet aangeraakt).

**Waardebalk daadwerkelijk aan het productsjabloon gekoppeld.** RUN 3 bouwde het blok `blocks/hi-pack-value-bar.liquid` al, maar kreeg het niet in een productsjabloon ("tooling-limiet"). Deze run is dat alsnog gelukt: in `templates/product.json` (sectie `main` → blok `product-details`) is een blokinstantie van het type `hi-pack-value-bar` toegevoegd direct ná de variant-picker en vóór de Bundler-blokken/bestelknop — de plek die de blokdocumentatie zelf aangeeft. Instellingen op de standaardwaarden (drempel €35, teksten uit het schema), die overeenkomen met het feitenbestand. `validate_graphql_codeblocks` gedraaid vóór de `themeFilesUpsert`-mutatie (verplicht, harde regel 5); resultaat `userErrors: []`.

Nog te doen (mensenwerk): visueel controleren in de theme-editor preview en besluiten of/wanneer dit naar het live thema gaat. Pas na publicatie kan de test (nulmeting add-to-cart 9/276 = 3,3%, zie RUN 3) echt lopen.
