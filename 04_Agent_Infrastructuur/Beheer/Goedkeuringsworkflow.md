# Goedkeuringsworkflow — Website Agent

> Hoe voorstellen en wijzigingen van de Website Agent goedgekeurd worden voordat ze live gaan. Voor de volledige taakverdeling: zie [[Agent Takenverdeling & Grenzen]].

---

## Shopify: apart theme, nooit live

De agent werkt altijd in het **"HÏ Grip website AI Workspace"**-theme, nooit rechtstreeks in het live theme op www.higrip.nl en nooit in een van de overige oude/duplicate thema's. De actuele theme-ID's staan op één plek: [[Technische Procedures]] § "Harde regel — theme-ID's" (daar ook het volledige technische hoe).

1. Agent bouwt/wijzigt secties in het AI Workspace-theme
2. Lars beoordeelt de wijziging (preview-URL)
3. Bij akkoord: **lars kopieert de wijziging zelf** naar het live theme — de agent publiceert nooit zelf naar live

**Why:** lars wil expliciet zelf de laatste stap naar live zetten, ook als een wijziging al inhoudelijk is goedgekeurd.

## Overige categorieën

Voor voorstellen buiten Shopify-code (copy, SEO-meta, vault-documentatie) geldt het niveau zoals vastgelegd in [[Agent Takenverdeling & Grenzen]] — "Voorstellen, ik keur goed" betekent: agent deelt het concept, lars keurt goed, pas dan gaat het verder (bv. daadwerkelijk in de vault-notitie zetten).
