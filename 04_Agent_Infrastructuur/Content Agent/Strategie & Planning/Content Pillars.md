# Content Pillars

Vastgesteld 14-9-2026. Dit zijn letterlijk ook de 3 tags in Buffer's ideeënbord (Buffer staat maximaal 3 tags per organisatie toe, dus pillar = tag, 1-op-1).

## 1. Persoonlijke content
Achter-de-schermen, oprichter/team, eerlijke/rauwe momenten. Geen gepolijste productie — dat is het punt.

## 2. Aankondiging content
Product-launches, restocks, acties, seizoensgebonden aankondigingen.

## 3. Performance & Lifestyle content
Sport-in-actie (tennis, padel, voetbal, Hyrox e.d.) én de brug naar dagelijks leven — presteren op het veld en grip op je dag.

## Koppeling aan Buffer
- Elke pillar = exact 1 Buffer-tag, zelfde naam.
- Tags worden handmatig aangemaakt in Buffer (de API kan geen tags aanmaken, alleen bestaande tags toepassen) — zie [[Agent Takenverdeling & Grenzen — Content Agent]] voor de volledige technische beperking.
- Tag-ID's staan vastgelegd in [[Buffer Tag ID's]] zodra ze zijn aangemaakt.
