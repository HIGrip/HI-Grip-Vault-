# Content Pillars

Vastgesteld 14-9-2026. Dit zijn letterlijk ook de 3 tags in Buffer's ideeënbord (Buffer staat maximaal 3 tags per organisatie toe, dus pillar = tag, 1-op-1).

## 1. Persoonlijke content
Achter-de-schermen, oprichter/team, eerlijke/rauwe momenten. Geen gepolijste productie — dat is het punt.
Buffer-tag: **PERSOONLIJKE CONTENT** — id `6a32de319c923d4b7e026a68`, kleur `#87C221`.

## 2. Aankondiging content
Product-launches, restocks, acties, seizoensgebonden aankondigingen.
Buffer-tag: **ANNOUNCEMENT CONTENT** — id `6a32de2b355ff4514e0783f5`, kleur `#1F35B3`.

## 3. Performance & Lifestyle content
Sport-in-actie (tennis, padel, voetbal, Hyrox e.d.) én de brug naar dagelijks leven — presteren op het veld en grip op je dag. Buffer-tag omvat ook influencer-content.
Buffer-tag: **PERFORMANCE / LIFESTYLE / INFLUENCER CONTENT** — id `6a32de22b853eaf5dd01bac5`, kleur `#E0364F`.

## Koppeling aan Buffer
- Elke pillar = exact 1 Buffer-tag. De 3 tags bestonden al in Buffer (lars had ze al aangemaakt) toen dit werd vastgelegd op 14-9-2026 — de agent hoefde ze dus niet zelf aan te maken (kan ook niet, de API kan geen tags aanmaken).
- Nieuwe ideeën worden door de Content Agent altijd met exact één van deze 3 tags in Buffer's ideeënbord gezet (groep: Unassigned) — zie soul.md.
